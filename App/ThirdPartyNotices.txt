■ NVIDIA CUDA ランタイム（アプリに同梱: cudart64_12.dll, cublas64_12.dll, cublasLt64_12.dll — CUDA 12.4）
https://developer.nvidia.com/cuda-toolkit
whisper.cpp の公式 Windows CUDA ビルドに含まれる再頒布可能なランタイムです。
NVIDIA Software License Agreement / CUDA Toolkit End User License Agreement（Attachment A に記載の
再頒布可能ファイル）の条件に従って同梱しています。全文: https://docs.nvidia.com/cuda/eula/
GPU で処理するには NVIDIA のグラフィックスドライバー（nvcuda.dll）が必要です（アプリには含みません）。
